# Improve conversation reliability and contextual multi-document RAG

Conversation history used the LLM context limit as its UI response limit, and Mastra serialization hid provider-error identity. This change separates owned history/list pagination from model context, preserves sanitized 429 metadata, retains failed turns and earlier messages, and passes bounded conversation history into the workflow.

Adaptive retrieval uses up to four focused TypeGraph hybrid queries, RRF fusion, chunk deduplication and document diversity with existing authorization/version filters. Document questions skip redundant structured-schema planning; actual analytics preserve column and aggregation intent. Qwen3 grounded execution uses the correct Ollama reasoning option, removes unused tool schemas, preserves answer language and overrides conflicting tool-oriented instructions. Authorized index metadata restores page/chunk provenance. Verified insufficient-evidence refusals remain valid refusals. A narrow multilingual guard also prevents short explicit insufficiency statements being cited as facts, and retains a clear draft refusal when verifier output is invalid. Missing queued version jobs can be restored by duplicate upload with the same BullMQ identity; processing orphans still require operator recovery. The isolated container stack uses the correct bind address and Redis AOF.
